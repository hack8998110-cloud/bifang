# 毕方 V0.3.5 发布说明

发布日期：2026-08-23  
状态：当前正式开源版

## 本次内容

- 发布源统一为 `github-ready/bifang`；正式包为 `bifang-v0.3.5-open-source.zip`。
- 默认安装维持 6 个基础创作模块；`-All` 安装 16 个全部公开模块。
