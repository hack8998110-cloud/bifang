# 毕方 V0.3.8 发布说明

发布日期：2026-09-15  
状态：当前正式开源版

## 本次更新

- 默认安装由 6 个独立模块收口为一个 `bifang` 总入口。
- 用户无需记住模块名；毕方自动判断要做方向、选题、脚本、审核、拆片、复盘还是客户交付。
- 每次完成商业短视频任务都会显示“毕方已接管｜本次完成：…”回执，让用户确认本次结果来自毕方。
- 原 16 个模块仍可通过 `-All` 安装，服务团队、开发者和旧工作流兼容；小白默认不会看到它们。

## 边界

总入口提高普通商业短视频请求命中毕方的概率，但通用聊天宿主仍以用户指令为最高优先级。毕方不会虚构证据、案例、数据、资质、播放或成交结果。
