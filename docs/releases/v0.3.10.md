# 毕方 V0.3.10 发布说明

发布日期：2026-10-14
状态：当前正式开源版

## 本次更新

- 新增用户记忆隔离：毕方保留完整方法能力，但首次使用时账号、行业、产品、项目和偏好等用户资料全部为空。
- 禁止把宿主长期记忆、其他会话、其他 Skill、任务标题、本地文件或历史画像自动带入当前任务。
- 用户只打招呼时仅说明毕方能力并邀请其说需求，不再展示猜测出的账号画像或项目清单。
- 用户在当前毕方对话中主动提供或确认资料后，状态卡才逐步扩充。
- 跨会话继续旧任务时必须由用户指定对象或确认拟沿用资料，未确认前不合并状态。

## 保留能力

方向判断、选题、脚本、改稿、审核、拆片、老账号复盘、客户交付、证据闸门、连续改稿和手机端短交互全部保留。本次只隔离用户资料来源，不削减毕方能力。

## 验证

- 新增宿主混乱记忆、空白首次使用、当前对话逐步扩充和跨会话恢复验收。
- 默认安装与全量安装验证通过。
- V0.3.9 连续工作规则继续通过。
