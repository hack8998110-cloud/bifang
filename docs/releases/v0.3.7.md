# 毕方 V0.3.7 发布说明

发布日期：2026-08-23  
状态：当前正式开源版

## 本次更新

- 将通用的内容判断规则同步到现有 7 个公开模块：入口、选题、脚本、审核、诊断、账号规划与证据包。
- 增加内容主功能与多人决策角色地图，避免一条内容承担所有目标、或把使用者与付款/决策者混为一谈。
- 完整脚本与审核新增“观看任务 / 证明任务”双标签：形式感可以帮助观看，但不算可信证据。
- 对客户原话、截图、案例、数据增加来源、范围、时间和可公开性要求；信息不足时退回补问、补拍、匿名化或待验证。
- 多账号矩阵保持可选，且必须有不同用户阶段、证据或承接，不得只是改标题重复。

## 不包含的内容

- 不包含研究过程、人物资料、原作表达、账号抓取材料、客户案例、内部报价或内测结果。
- 不承诺播放、咨询、到店、成交或平台算法效果。

## 验收

按 [开源发布验收清单](../../tests/open_source_acceptance.md) 的 G 项检查过程、案例、知识/观点和矩阵边界；原有安装、核心链路与回归用例仍需全部通过。
