# 毕方 V0.3.9 发布说明

发布日期：2026-10-13
状态：当前正式开源版

## 本次更新

- 新增连续工作约定：承接对话中已确认的账号、目标、候选选题、证据、稿件版本和审核结论，不重复询问。
- 支持“第 2 个”“就这个”“缩短一点”“接着改”等手机端短回复，默认绑定最近一次仍有效的候选项或稿件。
- 对外继续只呈现一个毕方；内部可在同一轮完成生成、审核和必要改稿，不要求用户理解模块名。
- 每轮完成后只给一个最自然的下一步；手机端首屏先给结论和可执行内容，展开信息不牺牲证据与边界。
- 新增会话状态卡与反馈纠错卡，用于连续选题、成稿、改稿、复盘和真实使用回归。

## 不变的底层逻辑

本次更新没有替换毕方原有的商业判断、内容主功能、观看理由/成交理由、证据闸门与审核标准。连续使用能力只负责传递已经确认的信息、减少重复操作和收短交互路径。

## 验证

- 默认安装仍只安装 `bifang` 总入口。
- 发布检查、默认安装验证、全量安装验证均通过。
- 连续对话验收覆盖编号选择、省略式改稿、单一下一步、状态重建与反馈纠错。
