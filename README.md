# 毕方 V0.3.8

![毕方编导思维逻辑](assets/bifang-v0.2-dev-pixel-promo-hero.png)

毕方是一套商业短视频内容判断 Skills：先判断用户真正想看什么，再生成选题、脚本、审核意见和发布复盘。

它不是账号管理 SaaS，也不承诺爆款。它帮助你把“我想卖什么”翻译成“用户为什么会看、相信和行动”。

## 3 分钟开始

首次使用只装一个毕方总入口：

```powershell
.\install.ps1
.\validate-install.ps1
```

然后在新的 Agent/Codex 会话中输入：

```text
我做【行业】，主要卖【产品/服务】；目标用户是【谁】；我想获得【到店/私信/成交】；我现有证据是【案例/现场/过程/反馈】。帮我看看今天该拍什么。
```

小白不需要知道模块名。毕方会自动判断你要的是方向、选题、脚本、审核、拆片还是复盘，并在结尾显示“毕方已接管”。

如果你是开发者、代运营团队，或需要单独使用兼容模块，再安装全部公开模块：

```powershell
.\install.ps1 -All
.\validate-install.ps1 -All
```

详细安装见 [安装指南](docs/guides/installation.md)，首次提问见 [快速开始](docs/guides/quickstart.md)。

## 你会得到什么

1. 用户真正想看的判断题；
2. 今天优先拍的内容；
3. 每条内容需要的真实证据和承接动作；
4. 已发布内容的保留、停止、重写与下一周计划。

## 一个入口，内部自动分流

| 分层 | 适合谁 | 模块 |
|---|---|---|
| 默认入口 | 所有小白用户 | `bifang` |
| 内部分流 | 方向、选题、脚本、审核、拆片、复盘、客户交付 | 毕方自动判断，不要求用户点名 |
| 全量兼容包 | 开发者、团队或旧工作流使用者 | 原 16 个独立模块 |

模块目录见 [`skills/`](skills/)。新用户只需要和 `bifang` 对话。

## 两条推荐路径

```text
新行业 / 新账号：毕方自动判断 → 方向 → 选题 → 脚本 → 审核
已有视频 / 老账号：毕方自动判断 → 拆片或复盘 → 下一步内容
```

产品能力说明见 [V0.3 产品说明](docs/product/v0.3-product.md)，当前版本变更见 [V0.3.8 发布说明](docs/releases/v0.3.8.md)。

## V0.3.8：小白总入口

- 默认安装从 6 个独立模块收口为一个 `bifang` 总入口。
- 用户说人话即可；毕方自动选择工作路径，并以“毕方已接管”回执让用户确认本次结果来自毕方。
- 原 16 个模块保留在 `-All` 安装中，供团队、开发者和旧工作流兼容使用。

## V0.3.7 方法增强

- 一条内容先确定一个主功能：获客、信任、转化、关系或生产；不让一条内容同时承担所有目标。
- 完整脚本的关键镜头同时说明“为什么值得看”和“凭什么可信”；自然表达、节奏和氛围不能替代过程、标准、案例或可核验事实。
- 客户原话、截图、案例和数据要标注来源、适用范围与可公开性；无法核验时退回补问、匿名化或待验证，而不是补写成事实。
- 只有明确有多个账号或团队生产需求时，才使用判断、实操、示范三类内容矩阵。

## 开源边界

公开仓库仅包含通用规则、匿名样例和可复现测试；不包含私有研究、达人资料、客户数据、报价或内测交付记录。历史材料统一放在 [`docs/archive/`](docs/archive/)，不进入发布包。
