# 客户试用提示词包

用途：当你要给潜在客户快速展示毕方能力时，直接复制下面的提示词。

## 1. 账号基础规划

```text
用毕方的编导思维，帮我给这个账号做一份客户能看懂的基础规划。

账号信息：
【粘贴账号简介、粉丝量、获赞、作品标题、置顶内容、主页截图文字】

客户行业：
【行业】

客户目标：
【私信/到店/成交/建信任/涨粉/收线索】

要求：
1. 不要直接写脚本。
2. 先判断用户真正想看什么。
3. 分析关键人物关系：用户在替谁做决定、怕谁不满意、想向谁证明自己选对了。
4. 输出当前最大问题、内容主线、30 天方向、首批 5 条先拍内容。
5. 每条先拍内容都要写清用户判断题、为什么会看、看完拿走什么、需要什么证据。
6. 最后给一段能发给客户看的总结。
```

## 2. 老账号 9 条内容复盘

```text
用 bifang-feedback 帮我复盘这个老账号，不要当新号处理。

播放最高的 3 条：
1. 【标题/开头/播放/互动/私信情况】
2.
3.

私信或成交最多的 3 条：
1.
2.
3.

经常发但无效的 3 条：
1.
2.
3.

请输出：
1. 内容资产分类：流量资产、信任资产、成交资产、无效消耗。
2. 当前最大偏差：有播放没咨询 / 有咨询没成交 / 账号标签不清 / 证据不足。
3. 用户真正想看的内容。
4. 下一周先拍 5 条。
5. 每条为什么先拍。
```

## 3. 从客户试用规划进入第一条脚本

```text
基于上面的账号基础规划，从首批 5 条里选最适合先测试的一条，用 bifang-script 写 60 秒抖音脚本。

要求：
1. 先写脚本前判断：用户判断题、第一句为什么停、看完拿走什么、信任证据、承接动作。
2. 第一 3 秒必须服务用户判断题，不要只套爆款句式。
3. 中段给判断标准或具体步骤。
4. 结尾自然承接，不要硬广。
5. 输出改稿锚点，方便客户改台词但不改丢用户视角。
```

## 4. 试用后收集反馈

```text
请根据这次客户试用输出，帮我生成 5 个反馈问题。

要求：
1. 问客户是否看懂用户真正想看什么。
2. 问客户是否认可首批先拍顺序。
3. 问客户是否能提供对应证据素材。
4. 问客户最想先拍哪一条。
5. 问客户愿不愿意继续做第一条测试脚本。
```

## 5. 给客户的发送话术

```text
这是我先用毕方给你做的一版账号基础判断。

这版先不写完整脚本，因为脚本一定要建立在“用户为什么看、为什么信、下一步怎么行动”上。

你先看三件事：
1. 你的客户真正想看的，是不是这类问题？
2. 这 5 条先拍内容，你有没有真实素材能支撑？
3. 如果只先拍 1 条，你最想从哪条开始？

你确认后，我再帮你把第一条写成可以拍的脚本。
```
