# 去 AI 感 / 人话对照（硬规则细则）

配合 SKILL「去 AI 感 / 人话交付」。成稿、选题、改稿、审核、拆片、复盘交付前必过。原则来源：[borrow-from-peers.md](borrow-from-peers.md)。黑话词表：[banned-corp-jargon.md](banned-corp-jargon.md)。专业≠书面：[professional-not-formal.md](professional-not-formal.md)。双受众：[audience-paths.md](audience-paths.md)。复盘卡：[review-card.md](review-card.md)。**广告腔/说教硬规则**：[rewrite-ad-preach.md](rewrite-ad-preach.md)。主页诊断：[account-home-diag.md](account-home-diag.md)。

## 总标准

> 后台有骨架，前台像人说；读得顺、拍得到、没有编的数。

## 通用禁写 → 改写

| 坏（AI/公司腔） | 好（人话） |
|---|---|
| 赋能门店私域转化闭环 | 让进店的人愿意留下联系方式或下次还来 |
| 打透品类心智、对齐颗粒度 | 先讲清楚「怎么判断值不值得买」 |
| 沉淀可复用抓手与链路 | 今天先拍这一条，拍完你就知道下一镜拍啥 |
| 构建信任资产与内容矩阵 | 先让人看见你怎么做的，再决定信不信 |
| 深度拆解底层逻辑 | 说人话：你卡在哪一步，我们就拍哪一步 |
| 单句 40 字逗号叠罗汉 | 拆成两句、三句；一句一个意思 |

完整词表见 [banned-corp-jargon.md](banned-corp-jargon.md)；交付前必须扫一遍。

## 例 A：三文鱼店老板娘

**场景**：社区生鲜店，老板娘出镜；决策＝这份三文鱼敢不敢买给孩子吃。

**坏口播（AI 腔）**  
「在当今消费升级的背景下，我们通过严选供应链赋能家庭餐桌，为您打造安心的品质闭环，让每一次下单都成为信任的沉淀。」

**好人话**  
「你家娃吃三文鱼，最怕什么？刺、不新鲜、不明来路。  
我给你看这一刀：从中间片开，刺在不在、色泽匀不匀，镜头跟着走。  
你对照着看，觉得行再决定买不买。」

**拍什么（轻量）**  
片鱼刀下去；掰开给镜头看刺与色；包装或冰鲜边界说一句。

**别拍错**  
不要只拍朦胧灯光和「高级感」空镜；证明靠这一刀，不靠旁白形容词。

## 例 B：短视频编导（接商家单）

**场景**：编导给餐饮店出选题；决策＝老板今天先拍哪条、会不会浪费半天。

**坏选题标题**  
「基于用户旅程的餐饮内容心智破冰与转化链路测试矩阵」

**好人话选题**  
「后厨这一锅从下料到出锅，老板你盯哪三步算放心」  
「外卖装盒到复热，哪些步骤不能省」  
「新客第一次点，看哪三条再决定下单」

**坏交付习惯**  
一次甩六维评分表 + 完整分镜 + 「爆款公式 87 分」。

**好交付习惯**  
三条选题人话讲完 → 为什么先拍说两句 → 下一步：回 1/2/3 我写成可念稿。评分表不主动上桌。

## 例 C：口语化自检失败 → 当场改

**原句**：「我们将通过可视化过程与可核对标准，系统性解决用户在决策链路中的信任缺口。」  
**改后**：「你怕不放心，我就把过程拍给你看，并告诉你盯哪几步。」

**原句**：请围绕「抓手」沉淀本周内容资产。  
**改后**：这周先拍这三条；拍完回我编号，我帮你写成稿。

## 例 D：技工 / 汽修师傅

**场景**：汽修店师傅出镜；决策＝这次保养/检修该不该在这家做、工时和料是否说得清。

**坏口播（AI 腔）**  
「我们以数字化诊断赋能养车体验，打通检测—维修—交付全链路闭环，为车主沉淀可信赖的门店心智。」

**好人话（判断+边界）**  
「车抖、异响、灯亮，你最怕什么？查不准、乱换件、工时说不清。  
今天镜头跟我走三步：先报故障现象，再给你看检测点，最后口头报工时和必换/可换。  
你听得懂再决定修不修。没查清之前，我不承诺『一定是某某件』。」

**拍什么（轻量）**  
故障现象一句；检测仪/听诊/举升可见动作；工时与件类口头分类（必换 vs 建议）。

**别拍错**  
不拍「高端车间氛围」空镜顶替检测过程；不编「全国最低价/一次修好永不坏」。

**边界**  
只讲判断标准与流程；不写包过年检、绝对根治、未核验的「xx 公里无故障」案例。

## 例 E：合规医美咨询（高风险 · 禁疗效承诺）

**场景**：医美机构咨询师出镜；决策＝要不要先做面诊/了解流程，不是「保证变美」。

**坏口播（违法/违规腔）**  
「保证瘦十斤、百分百有效、做完立刻年轻十岁，限时名额。」

**好人话（判断+边界，无疗效承诺）**  
「你纠结要不要来面诊，最怕什么？项目讲不清、适不适合你、术后要注意啥没人说。  
这条只讲三件事：咨询怎么问、适合/不适合的边界怎么标、需要哪些检查或知情材料。  
效果因人而异，我这里不承诺结果。愿不愿来，以面诊和书面说明为准。」

**拍什么（轻量）**  
咨询问诊清单出镜；「适合/不适合」边界纸片或口述；知情/冷静期等流程一镜带过（按机构真实流程，不编）。

**别拍错**  
不拍前后对比伪症例、不念「保证/绝对/100%」；不编客户变美故事。

**边界**  
命中 [high-risk.md](high-risk.md)：只写标准、流程、边界、专业确认；禁疗效/包过/绝对化。

## 例 F：工厂老板

**场景**：工厂/作坊老板出镜；决策＝客户或经销商看完后敢不敢谈样品/下小单，怕交期与品控戏精。

**坏口播（AI 腔）**  
「我们通过精益生产赋能供应链协同，构建品质心智与交付飞轮，助力客户系统性降本增效。」

**好人话（判断+边界）**  
「你下工厂单，最怕什么？样品和量产不是一回事、交期口头一套、出问题找不到人。  
今天带你看三处：打样台怎么对样、产线关键检哪一步、出货前谁签字。  
你对照着看。谈样品可以，没对上样之前我不承诺『一定和样品一模一样量产一万件』。」

**拍什么（轻量）**  
对样动作；关键检点（尺寸/外观/功能任选可拍项）；出货签字或批次标记。

**别拍错**  
不靠厂区航拍和「实力雄厚」旁白；证明靠对样与检点，不靠形容词。

**边界**  
不编产能日销、不写未核验的大客户名；交期只讲本厂可拍流程，不写绝对「绝不错期」。

## 密度速查（有时长时）

| 平台假设 | 约时长 | 口播字数粗量（含标点宜再少） |
|---|---|---|
| 抖音 | 30–45 秒 | 约 120–180 字 |
| 视频号 | 45–60 秒 | 约 180–240 字 |
| 小红书 | 30–45 秒 | 约 120–180 字 |

超密 → 当场删同义复述，给压缩版；不要说「你自己再改短一点」。

## 拆片 / 复盘：去 AI 短注

**拆片**  
- 对用户先给三句人话：可借什么结构、什么不能照搬、本方要补哪条证据。  
- 禁「对标心智打法拆解」「可复用抓手矩阵」。  
- 不鼓励整段照搬话术/数据/人设。

**复盘**  
- 用 [review-card.md](review-card.md)：主要矛盾 / 保留停止重写 / 唯一下一步。  
- 禁「账号势能复盘与内容飞轮诊断」；数据只写用户提供且可核对的，不编播放/成交。

## 机器闸（可选）

成稿或抽检时可用仓库脚本扫黑话 + 超长句（依赖：仅 Python3）：

```bash
python3 scripts/scan_oral.py path/to/oral.md
cat oral.md | python3 scripts/scan_oral.py
```

输出 `JARGON` / `LONG` 行号；`OK` 表示未命中。词表读 `banned-corp-jargon.md`；句长默认 >20 汉字（标点间）。**不替代**大声读测与人物语气判断。

用户说「再专业一点」→ 见 [professional-not-formal.md](professional-not-formal.md)，禁止改回方案腔。

## 验收口诀

读得出口、拍得到证、没有编的数；像老板娘/编导/技工/咨询师/厂长本人会说的话，不像方案汇报。
