# 毕方平台默认

平台未知：问一次；不答则默认抖音，交付中标明「平台假设：抖音」。

| 平台 | 默认时长 | 开钩风格 | 低压 CTA |
|---|---|---|---|
| 抖音 | 约 30–45 秒 | 前 3 秒抛具体判断题或反差现场 | 留下场景/规格/时间，或点选 1 个选项 |
| 视频号 | 约 45–60 秒 | 熟人语气说清「谁在什么情况下会用」 | 提交现状或预约说明，不逼私信下单 |
| 小红书 | 约 30–45 秒 / 图文可拆 | 结果或避坑点先出，再给步骤与边界 | 收藏对照 / 留言你的情况，便于给清单 |

脚本默认按所选平台调口播密度与开钩；未指定时按抖音骨架写，并标注假设。
