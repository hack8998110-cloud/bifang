# 审核 Checklist

对现成文案 / 脚本逐项勾选。面向用户只给结论、原因与锚点，不展示本表名。手机首屏：结论先、短。

## 通过（须全部为是）

- [ ] 用户、场景、决策问题清楚（或已标待验证假设）
- [ ] 单一内容主功能，未硬塞多个目标
- [ ] 观看理由与成交理由分开且都站得住
- [ ] 已声明脚本类型（教知识/晒过程/聊观点/讲故事四选一），且类型服务于成交理由，非堆砌讲法
- [ ] 已显式点名至少 1 个爆款元素（可写「今天用了：…」），且元素服务观看理由并接到证据，非只罗列名词
- [ ] 证据闸门通过：有可拍证明，非纯氛围
- [ ] 关键镜头均有观看任务 + 证明任务
- [ ] 案例/数据/原话有来源与边界；无虚构
- [ ] 高风险行业无禁写表述（见 high-risk.md）
- [ ] CTA 低压，未逼单
- [ ] 判断锚点明确，改稿时保得住
- [ ] **口语化 / 去 AI 通过**（见下；含黑话词表扫描；不过则打回或先改人话再交）

## 口语化 / 去 AI（审核必过）

- [ ] **已扫描** [banned-corp-jargon.md](banned-corp-jargon.md)：核心禁写零命中；同义变体已改或标出
- [ ] 口播以短句为主，单句宜 ≤20 字；无书面长难句
- [ ] 无正确但没信息的空话
- [ ] 大声读不卡顿、不像念 PPT
- [ ] 未把字段名/评分表当用户菜单；默认轻量拍摄说明（口播+拍什么+机位+别拍错）
- [ ] 已知时长时密度合理，或已提供压缩版
- [ ] 语气贴合人物/行业，非通用播音腔
- [ ] 人话未变成乱承诺（无来源效果已改写为标准/流程/边界）
- [ ] **无广告催单腔 / 无老师训人腔 / 教学非上课体**（见 [rewrite-ad-preach.md](rewrite-ad-preach.md)）；要改稿时走改稿一等路径

## 打回（任一命中即打回）

- 缺真实证据仍写成「可拍成稿」
- 证明任务被氛围/表情/快剪替代
- 未声明脚本类型，或类型与决策/成交理由明显脱节
- 未点名爆款元素，或只列名词不落地
- 虚构或未核验材料写成既成事实
- 高风险承诺疗效/收益/包过/绝对化
- 改丢原决策问题或核心证据
- 平台/时长与用户要求明显冲突且未说明
- **口播 AI 腔明显**（长难句、黑话、念 PPT 感）且未改到可读顺
- **命中 banned-corp-jargon 核心禁写**未改
- **对小白甩了模块菜单/六维评分表**充当交付
- **广告腔明显**（限时催单/名额恐吓/空喊品质）未改到可看语
- **说教/上课体明显**（你要明白/科普起手式/系统讲解大纲）未改到跟着做

## 输出格式

```text
结论：通过 / 打回
原因：（一条说清）
保留锚点：
若打回：补拍或改写要点（最多 3 条）
下一步：（唯一动作）
```

打回若因口语化失败：改写要点须给出「坏句 → 好人话」至少 1 例，再让用户选是否采纳改稿。
