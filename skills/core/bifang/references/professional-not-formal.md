# 专业 ≠ 书面 / 方案腔（负例）

用户说「再专业一点」「专业版」「更专业」时：**禁止**把人话改回方案腔、书面长句或公司黑话。  
专业 = 更准的**标准 / 证据 / 边界**，不是更长书面句。

配合 [anti-ai-voice.md](anti-ai-voice.md)、[banned-corp-jargon.md](banned-corp-jargon.md)。受众差异见 [audience-paths.md](audience-paths.md)。

## 硬规则

1. 「再专业一点」→ 补：可核对标准、拍到什么算够、适用/不适用边界、证据来源或待核项。
2. 不得：加赋能/闭环/心智等；把短句并成长难句；把柜台/车间口气改成汇报腔。
3. 编导要「好交客户」→ 用 [audience-paths.md](audience-paths.md) 的编导可见层；仍禁核心黑话。
4. 改完再扫词表 + 大声读；像人说、标准更硬，才算过。

## 负例：用户说「再专业一点」

**改前（人话，可用）**  
「你家娃吃三文鱼，最怕刺和不新鲜。  
我给你看这一刀：刺在不在、色匀不匀。  
你对照着看，再决定买不买。」

**坏（滑回方案腔）❌**  
「我们将以可视化品控闭环打透品类心智，系统性沉淀家庭餐桌的信任资产，赋能每一次决策。」

**好（真·专业）✅**  
「标准三句：中间片开无外露大刺；肉色匀、无腥臭；冰鲜边界口头说清（到店几小时内、怎么验）。  
拍到什么算够：刀下去 + 掰开给镜头 + 边界那一句入镜。  
不适合：只拍朦胧灯光、不说验货边界。」

## 再一例：技工

**改前**：「今天跟我看三步：报现象、看检测点、口头报工时和必换/可换。」

**坏❌**：「对齐检测—维修全链路颗粒度，构建门店专业心智。」

**好✅**：「专业补丁：检测点必须出镜；必换/建议分两类说；没查清不承诺『一定是某某件』。」

## 自检一句

用户要专业 → 问自己：标准/证据/边界更清楚了吗？还是只是句子变长、更像方案？后者一律打回。
