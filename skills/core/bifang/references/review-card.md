# 账号复盘极简模板

有历史作品、数据或账号问题时用。对用户只出人话三句；禁复盘黑话（心智打法、内容飞轮、势能诊断等）。

扫词表：[banned-corp-jargon.md](banned-corp-jargon.md)。短注见 [anti-ai-voice.md](anti-ai-voice.md)。

## 人话三句（默认可见）

```text
主要矛盾：（一句：现在卡在哪）
保留 / 停止 / 重写：
- 保留：…
- 停止：…
- 重写：…（可只填仍相关的项）
下一步：（唯一可执行动作）
```

## 硬规则

1. 先主矛盾，再动作；不写长篇账号体检表。
2. 数据只写用户提供且可核对的；不编播放/成交。
3. 唯一步：只能有一个下一步（先拍哪条 / 停哪类 / 补哪条证据）。
4. 「再专业一点」→ 补证据边界与停/重写理由，不改回方案腔（见 [professional-not-formal.md](professional-not-formal.md)）。

## 坏 → 好

**坏**：账号势能与内容飞轮诊断显示心智链路未闭环……  
**好**：主要矛盾：老片全是氛围空镜，决策问题没入镜。保留：出镜人像能信。停止：只拍灯光文案。重写：下一条必须带可核对标准。下一步：回我一条代表作逐字稿，我标该停的三句。

## 与主页诊断卡

用户贴了主页简介或作品标题列表、并问「方向怎么调」→ 改用 [account-home-diag.md](account-home-diag.md)（含方向条）。  
本卡仍用于：只有几句历史问题、或要把诊断压成三句时。字段「保留/停止/重写」两边同义，不另造词。

用户在复盘后说「排两周/给我日历」：先补 3–5 条方向条（或沿用主页诊断的），再按 [direction-calendar-14d.md](direction-calendar-14d.md) 摊 14 天；不要从三句复盘直接跳空日历。

结果要**给老板/客户看** → 压成 [agency-deliverable-card.md](agency-deliverable-card.md)（人设一句 + 保留停止重写 + 方向条 + 唯一步；无评分、无模块名）。
