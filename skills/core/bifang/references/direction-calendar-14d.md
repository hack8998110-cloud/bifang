# 两周占位日历（可选 · 轻量）

把已有 **3–5 条选题级方向条**摊成 **14 天占位**。  
**默认不出**；仅当用户说「排两周」「给我日历」「按天排一下」「这两周哪天拍什么」时启用。

前置：须已有方向条（来自 [direction-strip.md](direction-strip.md) / [account-home-diag.md](account-home-diag.md)）。没有则先出方向条，再问是否排两周——**不要**跳过方向条直接甩 14 天空表。

原则借鉴（非原文）：GitHub `ootto-ai/claude-content-skills` content-calendar（2 周、由 3–5 支柱摊开、可轮换、可一批拍）；SkillHub `omni-content-matrix` / Scheduler **只借「节奏占位」**，不借多平台作战表、选题评分、栏目占比长文。详见 [borrow-from-peers.md](borrow-from-peers.md)。

## 输出格式（对用户可见）

```text
两周占位（假设从周几起：…；平台假设：…）

D1 周X：<一句话选题级>（方向条 #n）
D2 周X：休整 / 补拍素材
D3 …
…
D14 …

（可选一行）一批拍：D1+D3+D5 可同一天在厂里连拍对样/检点。

下一步：回某一天编号（如 D3）我写成可拍稿；或说「改密度」我加减休整日。
```

回执：`毕方已接管｜本次完成：选题`（日历是方向条的排期层，不对用户说模块名）。

## 硬规则

1. **每天最多 1 条**选题级占位；其余标「休整」或「补拍某某证据」。禁止一天塞 2 条以上。
2. **14 行都要有**：发内容或休整/补拍，不留空白行让用户猜。
3. 每条占位 = [topic-card.md](topic-card.md) 一句话选题级；**不是**分镜、口播全文、多平台改写、评分表。
4. 必须轮换方向条编号，避免连续 3 天同一条复读；「重写」向至少出现 1 次（承接 0.3.17 空标签规则）。
5. 默认节奏偏可持续：实体商家常见 **5–8 更/两周**（其余休整）；用户点名「天天更」再加密，并标假设「可能拍不过来」。
6. 不编「哪天流量好」；不写具体钟点，除非用户给过发片习惯。
7. 高风险行业占位仍受 [high-risk.md](high-risk.md)；证据不足的天写成「补拍：…」优先于硬排成稿日。
8. 禁黑话；禁六维/健康分；禁 B站+小红书+抖音一张表。
9. 唯一步：回 D 编号成稿，或改密度——不要同时甩「再出下两周」「拆片」「建档」。

## 与方向条 / 主页诊断 / 复盘

| 场景 | 做什么 |
|---|---|
| 主页诊断刚出方向条 | 下一步可写：「回编号成稿；要的话我帮你排成两周。」**默认仍是回编号**，不自动出日历 |
| 用户只要日历 | 确认或复述方向条 3–5 条 → 再出 14 天 |
| 只有 review-card 三句、尚无方向条 | 先补方向条（或问要不要 3 条方向），再日历 |
| 用户回 D3 | 按该日选题走脚本路径；过证据闸门 |

## 坏 → 好

**坏**  
甩「抖音+视频号+小红书 14 天作战矩阵」+ 每天 Hook/Format/CTA/评分。

**好**  
只排一个平台假设；每天一行人话选题或休整；一批拍一句；回 D 编号成稿。
