# 主页诊断卡（粘贴也能用）

用户丢来主页简介、近期作品标题/口播摘要、或一段账号描述时用。  
**不要求**先有后台数据或真实链接；有链接且用户允许再另议（本页默认粘贴输入）。

与 [review-card.md](review-card.md) 衔接：本卡偏「主页+片单快诊 + 2–4 周方向条」；review-card 偏「已有作品/数据问题时的人话三句复盘」。二者都用「保留/停止/重写」，**不互相发明第二套黑话**。  
方向条细则可另见 [direction-strip.md](direction-strip.md)（内容与本节「后续方向条」一致，免重复维护时可只改一处并互指）。

原则借鉴（非原文）：GitHub `inklate/social-skills` social-audit（粘贴证据、说清不可知、最大杠杆优先）；HBVD review（事实/假设/不能下的结论）；SkillHub 账号体检（**不借**打分表，只借「数据覆盖度要声明」）。详见 [borrow-from-peers.md](borrow-from-peers.md)。

## 输入（任一即可开诊）

| 类型 | 例子 | 够不够 |
|---|---|---|
| 主页简介粘贴 | 昵称+简介+置顶说明 | 可诊人设/CTA；片型弱 |
| 近期作品列表 | 标题或口播摘要 5–15 条 | 可诊片型/证据癖好 |
| 用户口述 | 「我们全是晒货+活动价」 | 可诊，须标假设 |
| 带少量数据 | 「这条播了 xx，那条不行」 | 只写用户给的数，不编 |

信息不够时：**先诊能诊的**，文首用一行写清「还缺什么会误判」；最多补问 1–3 个。不要问卷式画像。

## 固定输出（对用户可见）

```text
（可选）输入覆盖：简介✓/作品列表✓或✗/数据✗ —— 缺什么不能乱下结论

人设是否清楚：（一句：外人 3 秒知不知道你帮谁做什么选择）
片型是否单一：（一句：最近是不是同一种片；点名证据）
证据是否只会晒货：（一句：有没有过程/标准/边界，还是只堆货与形容词）
CTA：（一句：主页/片尾让人干什么；是否过硬或空洞）

保留 / 停止 / 重写：
- 保留：…
- 停止：…
- 重写：…

后续 2–4 周方向条：（3–5 条，选题级一句话，不是长方案）
1. …
2. …
3. …

下一步：（唯一：回方向条编号写成稿 / 补贴 N 条标题 / 先改编某条口播；可附一句「要的话我帮你排成两周」——用户未要则不甩日历）
```

回执：`毕方已接管｜本次完成：复盘`（主页诊断属复盘/诊断族；勿对用户说模块名）。

## 硬规则

1. **每句判断要能指回用户材料**（引用简介原句或标题）。指不回就标「假设」。
2. **不编播放、成交、限流原因**；无数据写「数据未知，不归因算法」。用户口述或粘贴的**公开粉丝/作品数**可以引用，并标明「公开量级/口述」；不得写成后台分析结果。
3. **不主动甩六维/健康分/总分表**（作者禁自嗨评分）。
4. **片型单一**与「支柱塌缩」用人话说：如「近 10 条里 8 条都是活动价口播」。
5. **晒货判定**：只有成品图/价格/口号、没有可核对过程或标准 → 点名「只会晒货」。
6. **方向条**必须是选题级短句（可直接进 [topic-card.md](topic-card.md) 极简层），禁止一次甩几十条；**默认禁止**主动甩按天长表。用户点名日历 → [direction-calendar-14d.md](direction-calendar-14d.md)。
7. 高风险行业方向条仍受 [high-risk.md](high-risk.md) 约束。
8. 扫黑话：[banned-corp-jargon.md](banned-corp-jargon.md)。

## 与 review-card 怎么分工（勿打架）

| 场景 | 用谁 |
|---|---|
| 只有「最近不行了/老片有问题」几句 | [review-card.md](review-card.md) 三句即可 |
| 贴了简介 + 作品列表，问「账号方向怎么调」 | **本卡**（含方向条） |
| 只口述「像素材号/私信不来」几句、无片单 | [review-card.md](review-card.md)；若随后补贴标题列表，升级本卡补方向条 |
| 本卡出完后用户说「先复盘主要矛盾」 | 可再压成 review-card 三句，方向条保留在下一步里 |
| 用户只要 3 条选题、不要诊断 | 走选题极简层，不硬上本卡 |
| 已有方向条且用户要排两周/日历 | [direction-calendar-14d.md](direction-calendar-14d.md)；仍不主动评分、不分镜 |

保留/停止/重写字段两边同义：本卡可写细一点，但不发明「飞轮/势能/心智」替代词。

## 坏 → 好（诊断口吻）

**坏**  
「账号基础盘 62 分，内容飞轮未闭环，建议矩阵化升级心智链路。」

**好**  
「人设不清楚：简介只写了店名，没说帮谁解决什么选择。  
片型单一：你贴的 8 条标题里 7 条是『今日特价』。  
证据偏晒货：没有过程镜和判断标准。  
保留：出镜人像能信。停止：纯报价口播连发。重写：每条至少带一个可核对标准。  
方向条：① … ② … ③ …  
下一步：回 1/2/3，我写成可拍稿。」


## 金样：工厂家具 / 素材号粘贴（摘要）

**输入特征**：简介偏「高级定制/工厂」；标题多「展厅扫镜、奢华、霸总、货架」；用户说私信少带户型。

**好诊（口吻）**  
人设半清楚：有工厂与客群词，但没说清「帮别墅业主把效果落地」。  
片型单一：近 N 条多数展厅/空标签。  
证据偏晒货：缺对样/交付边界。  
保留：工厂与本人出镜。停止：空标签连发。重写：一条一决策 + 引导发户型。  
方向条：对样差在哪 / 异地找厂保障 / 客厅先定哪三件……  
下一步：回编号成稿。

完整对话样例见内部 ab-test（脱敏合成；开源包不附真客户对话）。
