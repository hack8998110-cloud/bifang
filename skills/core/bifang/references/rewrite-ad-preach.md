# 改稿一等公民：广告腔 / 说教腔硬规则

有现成文案要改时优先读本页。目标：**短视频可看**，不是上课，不是硬广。  
商业判断、证据闸门、高风险边界**不因口语化而削弱**。  
交叉：[anti-ai-voice.md](anti-ai-voice.md)、[banned-corp-jargon.md](banned-corp-jargon.md)、[review-checklist.md](review-checklist.md)、[high-risk.md](high-risk.md)。

原则借鉴（非原文）：SkillHub `cn-de-ai-flavor`（老师腔/科普起手式）、`content-deai-engine`（口语重写）；口播「补主语、拆长句」（海螺社口语化常识，非抄文）；**不借**降 AI 检测率玩法。详见 [borrow-from-peers.md](borrow-from-peers.md)。

## 何时走「改稿」

用户丢来口播/标题/字幕/广告词，并说「改」「润色」「太广告了」「太说教了」「不像人话」「能不能让人愿意看」→ **改稿路径**（可与审核同轮：先标问题，再给改稿）。  
不要只给「通过/打回」而不给可用改句，除非用户只要审核结论。

## 总标准

> 看短视频不想被教育，也不想被推销压着；愿意跟着做、对照着看、自己下判断。

改稿三不：

1. **不改事实**：无新证据不编；无来源效果承诺改成标准/流程/边界。
2. **不改决策**：原片要帮观众解决的选择问题必须保住（见审核「保留锚点」）。
3. **不磨成同一种播音腔**：保留行业/人物语气（老板娘、师傅、编导……）。

## A. 广告腔 → 可看语

### 信号（命中 ≥1 须改）

- 限时 / 仅剩 / 名额 / 错过不再 / 全网最低 / 史低价
- 赶紧私信 / 立刻下单 / 扣 1 马上发 / 不买就亏
- 空喊品牌形容词：品质保障、匠心、赋能生活（叠黑话更糟）
- **空标签奢华词**：高级、奢华、轻奢、霸总、贵妇、气质拉满（无判断标准时一律当广告腔改）
- 只晒货无过程、无判断标准、无边界

### 改写原则

| 坏倾向 | 好倾向 |
|---|---|
| 催成交 | 帮做选择：盯哪几步、什么情况别买 |
| 夸词堆砌 | 可拍证据：过程、对照、标准一句 |
| 硬 CTA | 低压承接：问场景/现状/要不要看下一条 |

### 坏 → 好

**坏**  
「家人们！全网最低价三文鱼，今天只剩最后 20 盒，赶紧私信我下单，错过亏一年！」

**好**  
「娃吃生鱼片，你最怕哪样？刺、不新鲜、来路不明。  
镜头跟这一刀：中间片开，刺在不在、色匀不匀你自己看。  
觉得行再决定买不买。想看冰鲜边界，回我『边界』。」

**坏**  
「我们以匠心品质赋能餐桌，限时福利速速抢购！」

**好**  
「你对照着看三步：进货标、开箱、下刀。  
哪步对不上，这条就不建议你下单。」

**坏（豪宅/工厂素材号）**  
「这才是真正的豪宅家具！高级、奢华、霸总同款，名额有限赶紧私信！」

**好**  
「别墅家具最怕啥？样品好看，量产变样。  
今天只看打样台怎么对样。对不上，我不承诺一模一样。  
你家在装，把户型、预算、风格参考发我，先谈打样边界。」

## B. 说教 / 老师训人 → 短视频可看语

### 信号（命中 ≥1 须改）

- 「你要明白」「正确的是」「很多人都不懂」「我来教你」「务必记住」
- 培训课表腔：「本章」「下一节」「课后练习/练习册」「系统学习 XX 方法论」
- 科普起手式：「在当今……背景下」「所谓 XX，是指……」
- 自问自答上课体：问完立刻念讲义，观众插不进嘴
- 「不是 A，而是 B」连排三连（空洞对比）
- 道德绑架：不懂就别做、外行不要碰

### 改写原则

| 坏倾向 | 好倾向 |
|---|---|
| 我教你 | 我带你看 / 你跟着做一步 |
| 抽象正确 | 具体场景 + 当场可核对 |
| 训人 | 同行吐槽 / 自己踩过的坑 |
| 长定义 | 一句人话 + 镜头证明 |

### 坏 → 好

**坏**  
「你要明白，正确的保养观念是定期检测。很多人都不懂底层逻辑，我来系统讲解发动机健康知识。」

**好**  
「车抖的时候，你是直接换件，还是先查清再修？  
今天跟我走三步：报现象 → 看检测点 → 口头分清必换和可换。  
没查清之前，我不说『一定是某某件』。」

**坏**  
「在当今消费升级背景下，所谓新鲜，是指供应链全程冷链可控……」

**好**  
「你问鲜不鲜，别听形容词。  
看两处：冰鲜标签时间、开箱这一刀的色和味。  
对不上，就别买。」

## C. 工具 / 技能教学 →「愿意跟着做」而非上课

教学类短视频最容易变成网课。毕方默认改成 **跟做一条**：

1. **开场**：对方此刻卡在哪一步（不是课程大纲）。
2. **中间**：只带做 1 个小结果（按一下、改一处、拍一镜）。
3. **收束**：怎样算做对 + 什么情况别硬做（边界）。
4. **CTA**：低压——「你卡在第几步，回数字」；不推销「完整课」。

### 坏 → 好

**坏**  
「本章我们学习短视频选题方法论，请务必掌握用户心智与内容飞轮，课后完成练习册。」

**好**  
「选题卡死时，先写一句：观众看完要不要做某个决定。  
你现在回我你的行业 + 这句话，我帮你压成 3 条能拍的。  
先把第一条拍出来，再谈后面的。」

**坏**  
「Excel 有 108 个函数，下面系统讲解前 30 个，请记笔记。」

**好**  
「只要你会用『筛选』，今天就能把坏单挑出来。  
打开表 → 点筛选 → 按状态勾『待处理』。  
做完截图回我，我告诉你下一步勾哪一列。」

## 改稿交付格式（默认）

```text
改稿结论：广告腔 / 说教腔 / 教学上课体 / 混合（点名）
保留锚点：（原决策问题或核心证据一句）
坏 → 好：（至少 1 组；用户要全文则给全文改写）
口播改写：（说得出口的短句；已知时长则控密度）
拍什么 / 别拍错：（轻量；证据不够则列补拍）
下一步：（唯一：采纳改稿 / 补某条证据 / 回编号成稿）
```

不要主动甩六维评分。扫 [banned-corp-jargon.md](banned-corp-jargon.md)；大声读测；高风险见 [high-risk.md](high-risk.md)。

## 与审核的关系

- **只要结论**：走 [review-checklist.md](review-checklist.md)，打回时仍须 ≥1 组坏→好。
- **要可念稿**：本页为主，审核项作后台自检。
- 打回原因含广告腔/说教时，引用本页信号名即可，勿堆内部术语。
