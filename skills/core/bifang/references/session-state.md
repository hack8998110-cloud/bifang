# 毕方连续状态卡

仅在同一毕方任务需要从选题继续成稿、从脚本继续改稿、或从作品数据继续复盘时读取。状态卡用于传递当前毕方对话已经确认的结论，不作为面向用户的问卷，也不得自动导入宿主记忆或其他 Skill 状态。

单轮/单会话内存即可，默认不必落盘；仅用户要求或跨会话确认后才持久化。

## 字段

```yaml
state_scope: 当前毕方对话 / 用户明确指定并确认的旧毕方项目
account: 账号或业务对象；未知则留空
platform: 发布平台；未知则留空
content_goal: 获客 / 信任 / 转化 / 关系 / 生产
target_user: 谁在什么场景做什么选择
decision_question: 用户正在判断什么
watch_reason: 为什么停留和看完
conversion_reason: 为什么愿意行动
available_evidence: 已确认可公开的现场、过程、标准、案例、原话、数据或资质
evidence_gaps: 仍需补拍、补问或核验的材料
candidates: 最近一次有效的候选选题及编号
selected_candidate: 用户已选项；未选择则留空
draft_version: 当前稿件版本和用户要求
review_result: 通过 / 打回 / 待审核，以及不能改丢的锚点
performance: 已提供的发布数据；未知值保持未知
next_action: 当前任务完成后唯一的自然下一步
```

## 更新规则

1. 初次使用时除毕方能力外全部字段为空；不得用宿主长期记忆、其他会话、其他 Skill、任务标题或本地资料预填。
2. 只写用户在当前毕方对话中明确提供、当前对话已经确认或毕方标为“待验证假设”的内容；三者不能混写。
3. 当前毕方对话的新一轮先复用已有字段，不重新索取；跨会话状态只有在用户明确指定并确认后才复用。
4. 用户只回复编号时，从 `candidates` 解析并写入 `selected_candidate`，随后直接进入成稿。
5. 用户要求改稿时，保留 `decision_question`、`available_evidence`、`conversion_reason` 和最近一次 `review_result`；除非用户明确更换目标，不重新定方向。
6. 用户提供发布数据时，只更新明确给出的指标；缺失指标保持未知，不以 0 代替。
7. 新账号、新产品、新平台目标或新的商业任务会使旧字段失效时，明确指出改变了什么，再重建受影响字段；不要整张清空。

## 面向用户的最短回执

不要展示整张状态卡。只在需要消除歧义时说一句，例如：

> 沿用刚才第 2 个选题和已有的熬汤现场，直接写成 45 秒口播稿。

任务完成后只给一个动作：

> 下一步：回复“压到 30 秒”，我保留判断标准和现场证据继续改。

## 密度口令（0.3.23）

用户说改短 / 改长 / 改密度时：

1. 从上一轮 `draft_version` 取当前口播；**不要**因口令丢失而清空 `decision_question` / `available_evidence`。
2. 改完后更新 `draft_version`（注明短版/长版/疏版）与 `next_action`。
3. 上下文已有口播全文时，面向用户勿要求重贴；仅状态丢失时请贴回。

## 一条龙会话（0.3.24）：工作台四步串联

证明毕方是**工作台**不是散能力：同一会话可连续走完下列四步。脱敏金样（大彬类编导运营号）见 ab-test `v0324-replies/01-workbench-pipeline.md`。

### 四步触发

| 步 | 用户说法 / 情境 | 路径 | 写入 / 保留状态 |
|---|---|---|---|
| 1 诊失败 | 丢主页链接；作品区失败 | account-home-diag 诊失败回退 | `account` 粗画像；片型/晒货=未知；`next_action`=要标题 |
| 2 补标题重诊 | 贴 ≥8 条标题（或可辨截图） | 补标题→重诊 | 刷新片型/晒货/方向条→`candidates`；保留简介侧人设 |
| 3 今天先拍 | 「今天先拍 / 先写第一条 / 直接可拍」 | 诊后今天先拍（**可省**代运营壳） | `selected_candidate`=默认 1；`draft_version`=可拍口播；`decision_question`/`available_evidence` |
| 4 改短 | 「改短一点 / 再压 / 30 秒内」 | script-45s 密度口令·改短 | 更新 `draft_version`（短版）；锚点与证据字段不丢 |

### 承接硬规则

1. **同会话不要求重贴**：简介、标题列表、口播全文已在上下文 → 勿再要用户贴一遍。
2. **步 1 禁止假装读过作品**；步 2 标题已够仍写片型/晒货未知 = 违规。
3. **步 3 可省 agency 壳**；与壳「回编号成稿」等价。
4. **步 4 保决策锚点 + 证据句**；附「删了什么」；不回广告腔。
5. 任一步证据不足 → 补拍/补问，不成空稿；高风险/薛辉规则全程有效。
6. 不对用户展示状态卡字段名或「一条龙」模块名；人话说下一步即可。
