# 公司黑话 / AI 腔禁写词表（可更新）

成稿、选题、审核交付前**强制扫描**本表。命中则当场改人话，不得原样交给用户。

细则与坏→好例见 [anti-ai-voice.md](anti-ai-voice.md)。扫描步骤写入 [script-45s.md](script-45s.md)、[review-checklist.md](review-checklist.md)、SKILL「去 AI 感」节。

## 怎么扫（硬步骤）

1. 对用户可见全文（口播、选题一句话、为什么先拍、补拍清单、拆片结论、复盘下一步）做一遍字符串扫描。
2. 命中「核心禁写」任一词 → 必须改写；命中「同义变体」→ 优先改写，留一句说明为何改。
3. 字段名（观看任务、证明任务、选题卡、证据闸门、爆款元素表等）不对小白当菜单展示；需要时用白话一句带过。
4. 用户明确说「展开字段 / 要专业版 / 要评分表」时，可用内部字段，但仍禁核心黑话堆砌。
5. 改完再扫一次；仍命中则不算过关。

> 本表可随反馈增补。新增词写入「核心」或「变体」并在 CHANGELOG 记一笔。
>
> 可选机器闸：`python3 scripts/scan_oral.py <文件>`（读本表 + 标超长句；见 anti-ai-voice）。

## 核心禁写（直接命中即改）

赋能、闭环、抓手、沉淀、对齐、颗粒度、心智、链路、打法、底层逻辑、系统性解决、可视化过程、可复用资产、内容矩阵、信任资产、用户旅程、心智破冰、转化漏斗（对小白口播）、品类心智、深度拆解、价值主张、认知占领、心智占领、私域闭环、增长飞轮、链路闭环、打法闭环、对齐颗粒度、沉淀抓手

## 同义变体（优先改写）

| 变体/近义 | 改成人话方向 |
|---|---|
| 链路闭环 / 打法闭环 | 今天先拍哪条、拍完下一步是啥 |
| 心智占领 / 品类心智 / 认知占领 | 先讲清楚怎么判断值不值得买 |
| 沉淀可复用抓手 | 这周先拍这几条；拍完回编号 |
| 赋能门店 / 赋能转化 | 让进店的人愿意留下联系或下次还来 |
| 构建信任资产 | 先让人看见你怎么做的 |
| 系统性解决信任缺口 | 你怕不放心，就把过程拍给你看并说盯哪几步 |
| 基于用户旅程的…矩阵 | 三条人话选题 + 回 1/2/3 |
| 颗粒度对齐 / 对齐颗粒度 | 说清楚这一镜要证明什么 |
| 私域转化闭环 | 留下联系方式或下次还来的理由 |
| 增长飞轮 / 飞轮效应 | 先拍一条能复用的，再决定加不加第二条 |
| 价值主张 | 你凭什么让人多看一眼 / 愿意试一次 |
| 深度拆解底层逻辑 | 你卡在哪一步，我们就拍哪一步 |

## 允许（不算黑话）

- 「脚本类型」「今天用了：…」「平台假设：抖音」等产品约定白话
- 「证据不够先补拍」「低压承接」等判断用语（对小白可再白话成「先拍这些再写成稿」）
- 用户行业本身的词（技工说「扭矩」、汽修说「工时」、食堂说「复热」）——保留人物语气，不要磨成通用播音腔

## 快速自检口诀

扫完词表 → 大声读 → 像柜台/车间/咨询台会说的话 → 再交。
