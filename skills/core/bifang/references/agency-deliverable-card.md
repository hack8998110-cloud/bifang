# 代运营交付壳（给老板看）

代运营 / 编导要把结果交给**老板或客户拍板**时用。  
一张卡说清：人设一句、保留·停止·重写、方向条 3–5、唯一步。  
**不对老板**甩评分表、模块名、内部黑话、研究来源。

交叉：[account-home-diag.md](account-home-diag.md)、[review-card.md](review-card.md)、[direction-strip.md](direction-strip.md)。  
老板只关心「账号怎么调、下周拍啥」时，优先本壳；细节诊断仍可走主页诊/复盘卡，再压成此壳交出去。

## 何时用

| 用户说法 | 动作 |
|---|---|
| 「给老板看」「交客户确认」「代运营交付」 | 出本壳 |
| 主页诊 / 复盘已做完，要压成一页给决策人 | 从诊断结果压成本壳（字段同义，不另造词） |
| 老板只要选题、不要诊断过程 | 可只留人设一句 + 方向条 + 唯一步；保留/停止/重写仍建议保留一行 |
| 「报个价 / 代运营多少钱 / 接实体代运营」 | **先**主页三处检查，再挂「实体代运营从 8000 起」；可选题卡金样 → 见下节 |

## 老板可读卡（默认可见）

```text
人设一句：（外人 3 秒知不知道你帮谁做什么选择）

保留 · 停止 · 重写：
- 保留：…
- 停止：…
- 重写：…

方向条（3–5，选题级一句话）：
1. …
2. …
3. …

下一步：（唯一：回编号写成稿 / 补贴标题 / 先改某条口播）
```

回执：`毕方已接管｜本次完成：复盘`（对老板仍勿说模块名；勿写「agency-deliverable」）。

## 硬规则

1. **无评分**：不写健康分、六维、爆款分、基础盘分数。
2. **无黑话**：赋能/闭环/心智/飞轮/势能等禁出；扫 [banned-corp-jargon.md](banned-corp-jargon.md)。
3. **无模块名对老板**：不说主页诊断卡、方向条文件名、证据闸门等内部词；人话说「账号方向 / 接下来拍啥」。
4. **字段同义**：保留/停止/重写与主页诊、复盘卡一致，不发明第二套。
5. **方向条选题级**：能回编号成稿；默认不是日历。老板要排两周 → 再问一句确认后走 [direction-calendar-14d.md](direction-calendar-14d.md)。
6. **不编数据**：无播放/限流结论；缺材料写「还缺标题列表才能判片型」。
7. **高风险**仍受 [high-risk.md](high-risk.md) 约束。

## 与主页诊 / 复盘怎么挂

| 场景 | 用谁 |
|---|---|
| 粘贴简介+标题，自己先看清问题 | [account-home-diag.md](account-home-diag.md) |
| 只要三句主要矛盾 | [review-card.md](review-card.md) |
| 结果要交给老板拍板 | **本壳**（可从上面两卡压出） |
| 作品区读失败，只能简介 | 主页诊失败回退后，仍可用本壳的骨架，但片型/晒货标未知，方向条须标「待标题确认」 |

## 坏 → 好（交老板口吻）

**坏**  
「账号基础盘 58，内容飞轮未闭环，建议矩阵化升级心智；详见六维评估表。」

**好**  
人设一句：简介像店名广告，外人不知道你帮谁做哪类选择。  
保留：能出实物/现场。停止：连续报价口号当主粮。重写：每条带一个可核对标准。  
方向条：① … ② … ③ …  
下一步：老板回 1/2/3，我们写成可拍稿再交一版口播。


## 回编号成稿（衔接样例 · 脱敏）

情境：已交老板可读卡；方向条有 3 条；老板（或编导）回复 `2`。

**可见层应直接进入可拍稿，而不是再问「你是做什么的」：**

```text
按方向条 2 写成可拍稿（约 45 秒口播）：

脚本类型：晒过程
今天用的看点：反差 / 可核对标准

口播：
……（短句；保决策锚点；低压 CTA）

拍什么：三五句
机位：一句
别拍错：一句

下一步（唯一）：按这个拍；或回「缩短 / 换钩子 / 要分镜」。
```

毕方已接管｜本次完成：脚本

硬规则：无证据不成稿（改补拍清单）；扫黑话；对老板仍无模块名。session-state 须带上 `selected_topic` / `decision_question` / `available_evidence`。

## 自检

- [ ] 人设一句 + 保留停止重写 + 方向条 3–5 + 唯一步都有
- [ ] 无评分、无黑话、无模块名
- [ ] 未虚构播放/限流
- [ ] 缺作品列表时未假装判过片型
- [ ] 老板回编号后能直接成稿或补拍，不重问行业
- [ ] 若涉及报价：先三处再价；有「8000 起」人话、无套餐表

## 报价前三处 + 实体代运营从 8000 起（0.3.21）

用户要**报代运营价 / 接实体代运营**时：交付壳的「下一步」优先挂三处检查，而不是先甩价目表。

### 何时触发

| 用户说法 | 动作 |
|---|---|
| 「报个价」「代运营多少钱」「接实体代运营」 | 先三处（人设/片型/晒货）→ 再一句价 |
| 已有老板可读卡，老板问「那你们怎么收费」 | 三处结论一行 + 「实体代运营从 8000 起」+ 唯一步 |

### 下一步金样（挂在壳末尾 · 人话）

```text
下一步（唯一）：先回看主页三处——人设清楚吗 / 片型单一吗 / 是不是只会晒货；
过了再谈实体代运营（服务从 8000 起）。要可拍验证就回 1/2/3（三条=三处）。
```

也可把三处直接压成选题卡极简层 → [topic-card.md](topic-card.md)「代运营报价前主页三处检查」。

### 硬规则

1. **先检查后报价**：材料不够（无标题列表）→ 要 8–12 条；不编限流、不空口打包票。  
2. **8000 起是服务下限口吻**：一句人话即可；**不**甩套餐表、分期、六维报价矩阵。  
3. **无评分无黑话无模块名**（同壳总规则）。  
4. 高风险行业仍受 [high-risk.md](high-risk.md) 约束；报价话术不承诺疗效/收益。

### 自检（本段）

- [ ] 报价前出现三处（或明确要标题后再检）
- [ ] 价只以「实体代运营从 8000 起」一类人话出现，无套餐表
- [ ] 可回编号走选题卡金样 / 成稿
