# 约 45 秒口播 / 可拍脚本模板

默认按平台调时长（见 platform-defaults.md）。成稿前必须过 evidence-gate.md。

成稿前还必须：选定**脚本类型**（四选一，见 [xuehui-script-types.md](xuehui-script-types.md)）+ 至少 **1 个爆款元素**（见 [xuehui-viral-elements.md](xuehui-viral-elements.md)），并写进下方字段。

**成稿交付前必须过「口语化 / 去 AI」关**（见 [anti-ai-voice.md](anti-ai-voice.md)）；并**强制扫描** [banned-corp-jargon.md](banned-corp-jargon.md)。用户要「更专业」见 [professional-not-formal.md](professional-not-formal.md)；商家/编导口吻见 [audience-paths.md](audience-paths.md)。不过则改到过再交，不得把书面腔口播交给用户。

## 小白版输出顺序（默认）

对用户优先按此顺序交付，白话可执行；分镜表仅在用户要或复杂场面时追加。手机首屏：结论先、短。

1. **口播全文**（可直接念）
2. **拍什么**（三五句，说清关键画面）
3. **机位一句**（手机怎么架 / 跟谁拍）
4. **别拍错**（容易拍成氛围、拍丢证据的提醒）
5. **（可选）分镜表**

元信息字段仍要填全（含脚本类型、选用爆款元素），可放在口播前用两三行交代，或附在文末。对小白：字段名可收成白话（「脚本类型」「今天用的看点」），勿当菜单堆出。

```text
标题（口播可用）：
平台 / 时长假设：
目标用户与决策问题：
内容主功能：
观看理由 / 成交理由：
脚本类型：（教知识 / 晒过程 / 聊观点 / 讲故事，四选一）
选用爆款元素：（至少 1 个，建议 1–2 个；例：反差 + 最差）
今天用的看点（白话）：（例：今天用了：反差+最差）

【口播全文】

【拍什么】（三五句）

【机位】（一句）

【别拍错】

【分镜表】（可选）
镜号 | 画面（可拍） | 口播 | 观看任务 | 证明任务 | 时长约
1 |  |  |  |  | 3s
2 |  |  |  |  |
… |  |  |  |  |

【证据清单】
已用证据：
仍缺 / 待核：

【低压 CTA】
（提交场景、材料、规格、时间或现状；避免硬性私信下单）
```

## 交付前：口语化 / 去 AI 硬检（须全过）

- [ ] **黑话扫描**：已按 [banned-corp-jargon.md](banned-corp-jargon.md) 扫用户可见全文；核心禁写零命中，变体已改人话（可选机器闸：`python3 scripts/scan_oral.py <口播文件>`）
- [ ] 口播单句大多 ≤20 字；无逗号串成长难句（`scan_oral.py` 会标 LONG）
- [ ] 无正确但没信息的空话
- [ ] 大声读一遍不卡顿、不像念 PPT
- [ ] 默认只有口播+拍什么+机位+别拍错；未擅自甩完整分镜/评分表
- [ ] 已知时长时已估密度；超密已给压缩版
- [ ] 保留该行业/人物语气（老板娘 ≠ 编导 ≠ 技工 ≠ 医美咨询 ≠ 工厂老板 ≠ 通用播音腔）
- [ ] 无编造案例/数据；承诺已落到标准/流程/边界

任一不过 → 当场改口播再交，不把「先凑一版」甩给用户。

证据不够时：不填完整成稿，只输出补拍/补问清单（要拍什么、拍到什么算够）；仍可建议拟用的脚本类型与看点，但不假装已成稿。补拍清单也用人话写，不堆字段名；同样扫黑话词表。

## 密度口令（0.3.23）：改短 / 改长 / 改密度

用户在**已有可拍口播**之后说压时长、加细节、或念不过来时用。  
来源可包括：本页成稿、[rewrite-ad-preach.md](rewrite-ad-preach.md) 改稿、[account-home-diag.md](account-home-diag.md)「今天先拍」、[agency-deliverable-card.md](agency-deliverable-card.md)「回编号成稿」。

### 触发说法

| 用户说法 | 口令 | 做什么 |
|---|---|---|
| 改短一点 / 再压 / 压一压 / 30 秒内 / 压到 30 秒 | **改短** | 删铺垫与重复；**保留决策锚点与证据句** |
| 改长一点 / 再展开 / 加点细节 / 再丰满点 | **改长** | 只加**可拍**证据或过程细节；不加空形容词/说教 |
| 改密度 / 太密念不过来 / 再疏一点 / 加换气 | **改密度** | 拆长句、加换气点；**不改卖点** |

### 硬规则

1. **承接 session-state**：上一轮口播仍在上下文 → **勿要求用户重贴全文**；只在上下文丢失时请贴回。
2. **改短**：决策锚点 + 至少一句可核对证据/标准必须留下；删的是铺垫、同义复述、过长 CTA。禁止压成空口号。
3. **改长**：新增句必须可拍（过程/对照/标准/边界）；禁止堆「高级/赋能/一定要」类空词；不削弱证据闸门与高风险。
4. **改密度**：只动节奏（断句、换气），不换钩子、不换卖点、不改回广告腔/说教腔。
5. 扫黑话；无评分；不编数据。
6. 回执：`毕方已接管｜本次完成：改稿`（或「脚本」，若用户当续写成稿）。

### 输出骨架

**改短**
```text
压后口播（约 __ 秒假设）：
……

删了什么：（一句：如「删了开场铺垫两句、尾部重复 CTA」）

下一步：（唯一：按这个拍 / 再压 / 改密度 / 要分镜）
```

**改长**
```text
展开后口播：
……

加了什么：（一句：如「加了切割面停留 + 冰鲜红标准一句」）

下一步：（唯一：按这个拍 / 再压 / 改密度）
```

**改密度**
```text
疏后口播：（短句；可在换气处用 / 或换行标一下）
……

换气提示：（一句：如「每句末换气；『冰鲜红』后停半拍再念刺少」）

下一步：（唯一：按这个拍 / 再疏 / 改短）
```

### 金样口吻（承接「特价改决策题」口播）

**前情口播（约 45 秒）**：特价别只念价 → 定选择 → 镜头对切割面 → 标准：冰鲜红、刺少、能当天出 → 对比特价私信只问价 → 改标题发一条。

**改短（好）**  
压后口播：  
特价别只念价。  
先定客人纠结啥：这条鱼能不能进拼盘。  
镜头对切割面。  
标准就一句：冰鲜红、刺少、当天能出。  
拍完把标题改成这句决策题。

删了什么：开场铺垫收成两句；删了「私信问价」对比展开和尾部「丢给我看改没改到位」。

**改短（坏 · 禁止）**  
「家人们快来抢，今日特价，赶紧私信！」← 锚点与证据全丢，回广告腔。

**改密度（好）**  
疏后口播：  
你店里那条「今日特价」——别再只念价。  
先定一个选择：这条鱼，今天能不能拼进拼盘。  
镜头对着切割面。不对着价签。  
判断标准就一句：冰鲜红。刺少。能当天出。  
只喊特价，私信只会问多少钱。  
拍完，把标题改成决策题，发一条试试。

换气提示：「切割面」后换气；三个标准分成三短句念，勿一口气扫过。

**改长（好）**  
展开后口播：在原版上加「下刀停两秒让观众自己看色匀不匀」；加「刺用刀尖拨一下给镜头」——仍是可拍过程，无空夸词。

加了什么：切割面停留 + 拨刺一眼，方便观众自己核对。
