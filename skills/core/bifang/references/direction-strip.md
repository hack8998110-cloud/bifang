# 内容方向条（轻量）

诊断或复盘后的「下一步」用：**2–4 周、3–5 条选题级方向**；默认不是按天日历。用户点名「排两周/日历」→ [direction-calendar-14d.md](direction-calendar-14d.md)。  
主输出结构见 [account-home-diag.md](account-home-diag.md)；本页只钉规则，避免和主页诊断卡打架。

原则借鉴：SkillHub `omni-content-matrix` / TikTok Content Planner 的「周计划」思路 → **只借轻量条，不借大日历、多平台作战表**。

## 何时给

- 主页诊断卡默认附带；
- 用户说「接下来拍什么方向」「这两周怎么调」；
- review-card 三句之后用户追问「具体拍哪几类」。

## 格式

```text
后续 2–4 周方向条：
1. <一句话选题级方向>
2. …
3. …
（最多 5 条）
下一步：回编号，我按极简选题或成稿往下做。
（可选一句）要的话我帮你排成两周。
```

## 硬规则

1. 每条都要能拍、能回编号；像 [topic-card.md](topic-card.md) 一句话选题，不是栏目说明书。
2. 覆盖「保留」方向，避开「停止」方向；「重写」至少占 1 条。
3. **默认**不写每日排期、不写多平台矩阵表。用户点名「排两周 / 日历 / 按天排」→ 用 [direction-calendar-14d.md](direction-calendar-14d.md) 轻量 14 天占位（仍选题级，非分镜）。
4. 证据不足的方向可写，但须在下一步提示「先补拍什么」。
5. 禁黑话；禁评分。

## 补丁（0.3.17）

若诊断「停止」含空标签/纯展厅扫镜，方向条**至少 1 条**必须是「把某条晒货标题改成决策题」的重写向，不能 5 条全是新品类开拓。

## 可选升级：两周占位（0.3.18）

用户明确要日历时读 [direction-calendar-14d.md](direction-calendar-14d.md)。  
方向条下一步允许附一句「要的话我帮你排成两周」；**禁止**未点名就主动甩 14 天表。
