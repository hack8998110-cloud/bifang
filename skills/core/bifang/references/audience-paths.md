# 双受众路径：商家自拍 vs 编导交客户

选题/脚本默认口吻与可见层按**谁用这份交付**分岔。不要混用。

| | **商家自己拍** | **编导交客户** |
|---|---|---|
| 谁读 | 老板/店员，手机边拍边念 | 编导先读，再转给商家/客户确认 |
| 默认可见层 | 极简：一句话×3 + 为什么先拍 + 回编号 | 极简仍可先出；客户确认前可加「给客户看的一页」 |
| 口吻 | 柜台/车间第一人称；短句可念 | 对编导：可执行指令；对客户页：仍人话，禁方案腔 |
| 脚本默认 | 口播 → 拍什么 → 机位 → 别拍错 | 同上；可多一句「交给客户时保留的锚点」 |
| 「专业/展开」 | 补标准/证据/边界（见 professional-not-formal） | 可出字段短行 + 给客户确认的 3 条判断题；仍禁黑话 |
| 易混雷区 | 把编导内部备忘（类型表、评分）甩给老板 | 把老板自拍极简稿直接当「客户提案」却无确认锚点 |

## 怎么判

- 用户自称老板/店员/自己出镜 → **商家路径**。
- 用户自称编导/代运营/给客户做 → **编导路径**；可问一句「这份是给你自己用，还是要交客户？」信息已明则不问。
- 未表明：按说话语气偏商家则商家路径；出现「客户」「交稿」「提案」则编导路径。

## 可见层差异（选题）

**商家**  
今天先拍：1/2/3（人话判断题）→ 为什么先拍 → 回编号。

**编导（交客户时）**  
可先给编导极简三条；若要交客户，追加块（仍短）：

```text
【给客户看】
今天建议先拍哪条：（一条）
客户要拍板的三句：（判断题，可回是/否或选号）
不能改丢：（一句锚点）
```

## 脚本口吻一句对照

- 商家：「你盯我这一刀。」
- 编导备忘：「出镜人念口播；镜头跟刀，别切空镜。」
- 交客户页：用商家能懂的判断题，不用「心智/链路」。
