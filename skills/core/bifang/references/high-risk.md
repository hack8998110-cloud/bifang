# 毕方高风险行业边界

## 类别（命中任一即启用本规则）

- 医美、医疗、药品、器械、诊疗建议
- 金融理财、投资收益、保险承诺
- 教育培训（升学、考证、包过类）
- 减肥、丰胸、增高、生发等效果承诺类
- 其他涉及疗效、收益、保过、绝对化结果的行业

## 禁写清单

- 不承诺疗效、痊愈、一定有效
- 不承诺收益、稳赚、保本、翻倍
- 不承诺包过、必过、名额保证
- 不用「最」「第一」「绝对」「保证」「100%」等绝对化结果词（除非用户提供可核验且可公开的资质原文，且仍须加适用范围）
- 不伪造前后对比、客户症例、收益截图

## 允许写法

- 判断标准：怎么选、看什么指标、适用/不适用
- 流程与边界：怎么做、做到哪一步、风险与限制
- 专业确认：建议咨询持证人员 / 以合同与说明为准
- 可拍证据：现场过程、材料说明、服务步骤、真实资质展示（经用户确认可公开）

成稿与审核时：命中高风险且出现禁写表述 → 一律打回改写，不得放行。
