# 选题卡模板

每条选题按此骨架在**后台**填全（一批通常 3 条）。面向用户时不要展示「选题卡」模块名。

**选题交付前必须过「口语化 / 去 AI」关**（见 [anti-ai-voice.md](anti-ai-voice.md)）：一句话选题要像人说的判断题，不像报告标题。并扫描 [banned-corp-jargon.md](banned-corp-jargon.md)。商家自拍 vs 编导交客户见 [audience-paths.md](audience-paths.md)；「再专业一点」见 [professional-not-formal.md](professional-not-formal.md)。两周占位日历里的每日格 = 本页一句话选题级，见 [direction-calendar-14d.md](direction-calendar-14d.md)。

## 默认：极简可见层（手机首屏）

**除非用户明确说「展开」「展开字段」「要完整选题卡」「要专业版」**，对用户只出极简层：

```text
（可选一行）平台假设：…

用户真正想看的：（一句）

今天先拍：
1. <一句话选题>
2. <一句话选题>
3. <一句话选题>

为什么先拍：（一两句人话）

下一步：回复 1 / 2 / 3，我写成可拍稿（证据不够就先给补拍清单）。

毕方已接管｜本次完成：选题
```

极简层规则：

- **一句话选题 + 为什么先拍 + 回编号** 必须有；其余字段全部收后台。
- 不要主动甩：谁在选 / 主功能 / 脚本类型 / 今天用了 / 可拍证据 / 风险 等短行字段（除非用户要展开）。
- 后台仍须选好类型建议与爆款元素，用户回编号成稿时再写出「脚本类型」「今天用了：…」。
- 「还缺什么证据」可压成半句挂在下一步里，或等用户选号后再给补拍清单；不要默认出证据表。

## 展开层（仅用户要求时）

用户说「展开 / 展开字段 / 完整卡」后再输出字段版（可压成短行，仍禁黑话）：

```text
编号：
一句话选题：
目标用户（谁 / 场景 / 选择）：
决策问题：
内容主功能：获客 / 信任 / 转化 / 关系 / 生产（只选一）
观看理由：
成交理由：
脚本类型建议：（教知识 / 晒过程 / 聊观点 / 讲故事，四选一；先商业判断再选）
爆款元素：（至少 1 个，建议 1–2 个；白话可写「今天用了：…」）
可拍证据（已有 / 待补）：
低压承接：
第一条不能丢：
风险备注：（高风险行业填边界；无则写「无」）
```

## 对用户怎么写（硬规则）

- **默认极简**；字段骨架收后台。手机首屏：结论先、短。
- **一句话选题**：像能念出来的判断题（例：「三文鱼刺多不多，你盯这一刀」），禁报告标题腔与黑话。
- **为什么先拍**：一两句人话，不堆「抓手/闭环」。
- 类型与看点：展开时或成稿时用「脚本类型」「今天用了：…」；不解释内部八大名词表。
- 批次结尾只给一个下一步：回复 1/2/3。
- 澄清问题整批合计最多 1–3 个；能默认的写假设。

## 交付前：口语化自检

- [ ] 默认只有极简层（或用户已要求展开）
- [ ] 三条一句话都能大声读顺
- [ ] 已扫 [banned-corp-jargon.md](banned-corp-jargon.md)；无公司黑话、无模块菜单感
- [ ] 后台每条有类型建议 + 至少 1 个看点，且接到证据/决策（用户回编号后能写出）
- [ ] 唯一下一步；未同时甩建档/拆片/复盘入口

类型与元素细则：[xuehui-script-types.md](xuehui-script-types.md)、[xuehui-viral-elements.md](xuehui-viral-elements.md)。

## 金样：代运营报价前 · 主页三处检查（0.3.21）

**情境**（脱敏）：编导/代运营号要给商家**报实体代运营价**；手里有简介 + 若干标题（或先补贴）。初衷：报价前先用主页三处把账号说清楚，三条变成可拍验证，再挂价。

**三处**（与主页诊同义，不另造词）：

1. **人设清楚吗** — 外人 3 秒知不知道你帮谁做什么选择  
2. **片型单一吗** — 近几条是不是同一种片  
3. **只会晒货吗** — 有没有过程/标准/边界，还是只堆货与口号  

缺标题列表 → 先要 8–12 条，**禁止空口报价**。

### 极简可见层（选题卡金样 · 可原样骨架）

```text
用户真正想看的：报价前先看清账号三处，再谈代不代得了、值不值。

今天先拍：
1. 人设清楚吗：简介这句外人听得懂你帮谁选什么吗
2. 片型单一吗：近 8 条是不是同一种片（点名标题）
3. 只会晒货吗：有没有一条带可核对标准，还是全是价与口号

为什么先拍：三处过了，报价才有依据；不过先改方向，别空口报大数。

下一步：回 1/2/3 我写成可拍验证稿；三处过了再谈实体代运营（从 8000 起）。

毕方已接管｜本次完成：选题
```

### 后台（用户回编号成稿时写出）

| 编号 | 类型建议 | 今天用了 |
|---|---|---|
| 1 | 聊观点 | 反差 / 可核对标准 |
| 2 | 晒过程 | 对比（同片型堆叠） |
| 3 | 晒过程 | 可核对标准 / 边界 |

挂代运营壳：见 [agency-deliverable-card.md](agency-deliverable-card.md)「报价前三处 + 8000 起」。
