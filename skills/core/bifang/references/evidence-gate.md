# 毕方证据闸门

完整脚本必须过本闸门；未过则不交付成稿，只给补拍/补问清单。

## 够 / 不够

| 类型 | 判定 | 处理 |
|---|---|---|
| 过程 + 判断标准（可拍、可核） | 够 | 可成稿 |
| 对比前后 + 适用边界 | 够 | 可成稿 |
| 客户原话 / 案例 + 来源、时间、可公开性 | 够 | 可成稿；未核验则先标待核 |
| 数据 / 资质 + 适用范围 | 够 | 可成稿 |
| 仅氛围词（高级感、专业、放心、爆单） | 不够 | 必须补拍/补问 |
| 仅表情、冲突、快剪、BGM 情绪 | 不够 | 只能服务观看，不能代替证明 |
| 虚构案例、编造数据、无来源截图 | 不够 | 禁入稿；改为待核线索或删 |
| 「效果很好」「一定能」「保证」类绝对承诺 | 不够 / 高风险 | 改写为标准、流程、边界；见 high-risk.md |

## 成稿前自检（须全过）

1. 至少一项可拍真实证据已写入分镜或口播，且能对应证明任务。
2. 每个关键镜头同时有观看任务与证明任务；证明任务不得只靠氛围。
3. 未核验材料未写成已发生事实。
4. 高风险行业未出现禁写表述。

任一不过 → 输出补拍/补问清单（要拍什么、拍到什么算够、还缺哪句原话/数据），不输出完整可拍稿。
