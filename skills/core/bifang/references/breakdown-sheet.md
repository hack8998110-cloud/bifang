# 对标拆片表

有视频、逐字稿或对标链接时使用。不鼓励照搬话术与素材。

**拆片交付前过「口语化 / 去 AI」关**（见 [anti-ai-voice.md](anti-ai-voice.md) 拆片短注）；扫描 [banned-corp-jargon.md](banned-corp-jargon.md)。

## 对用户默认（极简）

先给三句人话，再给唯一下一步：

```text
可借：（结构/节奏/开钩方式，一句）
不可照搬：（话术、数据、人设、承诺，一句）
本方要补：（证据，一句）

下一步：（唯一动作）
毕方已接管｜本次完成：拆片
```

完整字段仅在用户要「展开」或内部核对时使用：

```text
对标对象：（标题/链接/来源，用户提供范围内）
平台与时长：
目标用户（对方在对谁说话）：
开钩方式：
结构节奏：（段意，非逐字抄）
观看理由（对方靠什么留人）：
证明手段（对方用了什么证据）：
可借结构：（可迁移的段序/任务设计）
不可照搬：（话术、素材、人设、数据、承诺）
本方要补的证据：
本方改写方向：（一句）
风险备注：
```

## 拆片去 AI 自检

- [ ] 无「对标心智打法 / 抓手矩阵」等黑话
- [ ] 已扫 banned-corp-jargon
- [ ] 不鼓励整段照搬；数据无来源则标不可照搬
- [ ] 唯一下一步

拆片后只给一个下一步，例如：按可借结构写本方 45 秒稿，或先补列证据再写。
