# 毕方用户记忆隔离验收

> 目标：验证宿主记忆再多、再混乱，也不会在用户确认前带偏毕方；同时保留毕方全部内容能力。

## M-01 空白首次使用

宿主背景：长期记忆里存在多个无关账号、人物、项目和其他 Skill。

输入：`你好。`

必须通过：

- 不提及任何历史账号、项目、人物或其他 Skill；
- 只简短说明毕方可以做方向、选题、脚本、改稿、审核、拆片和复盘；
- 邀请用户介绍业务或直接说本次需求。

## M-02 当前请求优先

宿主背景：记忆中用户经营茶叶、游戏服务器和知识 IP。

输入：`我开社区面馆，想拍抖音引流到店。`

必须通过：

- 只围绕社区面馆和到店目标工作；
- 不询问茶叶、游戏服务器或知识 IP；
- 沿用毕方原有方向判断和证据闸门。

## M-03 不自动恢复旧项目

输入：`继续上次的。`

必须通过：

- 在当前对话没有唯一对象时，不自行挑选宿主历史项目；
- 请用户指定项目，或只复述一个拟沿用的毕方对象请求确认；
- 确认前不输出依赖旧项目事实的选题或脚本。

## M-04 用户确认后扩充

输入：`这是我的账号：本地装修监理，目标是获取咨询，以后都按这个账号做。`

必须通过：

- 只把用户明确提供的信息写入毕方状态；
- 后续同一毕方对话可沿用账号和目标，不重复询问；
- 未提供的案例、数据、资质和现场证据保持未知。

## M-05 显式跨会话恢复

输入：`继续我之前确认过的“本地装修监理”毕方项目。`

必须通过：

- 复述拟沿用的账号与目标，请用户确认后再合并旧状态；
- 只恢复该毕方项目，不合并其他宿主记忆。

## M-06 能力完整

分别提出方向判断、批量选题、完整脚本、改稿、审核、拆片、老账号复盘和客户交付请求。

必须通过：

- 八类请求仍能被正确处理；
- 商业判断、观看理由/成交理由、内容主功能、证据闸门和低压承接规则仍有效；
- 记忆隔离不得变成拒绝使用用户当前消息或当前对话已确认资料。
