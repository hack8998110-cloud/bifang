# 示例：知识 IP / 课程顾问账号基础规划

## 基础信息

- 行业/赛道：知识 IP / 课程咨询 / 老板 IP
- 产品/服务：课程、陪跑、咨询、训练营、方法论交付
- 目标用户：有具体业务卡点的人、想提升获客/成交/管理/表达的人
- 客户想要的结果：建信任、私信咨询、报名体验课或陪跑
- 已有证据：学员案例、课堂片段、作业反馈、方法框架、复盘记录

## 1. 一句话判断

知识 IP 账号不要先讲“我有一套方法”，要先让用户判断：**这个方法是不是适合我当前的具体场景。**

## 2. 用户思维拆解

用户不是想看抽象认知，而是在判断：

- 我现在卡的问题是不是你能解决的。
- 你的方法是不是只适合别人，不适合我。
- 学完能不能落到具体动作。
- 你是不是只会讲理论。
- 有没有真实学员、真实作业、真实变化。
- 我现在该免费学、低价试，还是直接咨询。

关键人物关系：

- 工作关系：老板要求结果、客户要交付、团队要执行。
- 社会关系：同行对比、社群评价、朋友推荐。
- 家庭关系：时间和预算投入需要被家人理解。

## 3. 内容主线规划

### 主线一：具体场景卡点

- 不要讲“提升认知”，讲“客户说贵时你该怎么判断”。
- 不要讲“打造 IP”，讲“老板第一次出镜怕尴尬怎么办”。
- 不要讲“内容获客”，讲“发了 30 条没人咨询先查哪一步”。

### 主线二：方法可落地

- 一个学员作业改前改后差在哪里。
- 一个话术为什么能降低客户防备。
- 一个选题为什么能从泛流量改成精准咨询。

### 主线三：信任和边界

- 什么人不适合报课。
- 学完没有结果通常卡在哪里。
- 陪跑不是替你做，而是让你学会判断。

## 4. 首批最建议先拍的 5 条

### 1. 你发了 30 条内容没人咨询，先别怪流量，先查这 3 个判断题

- 用户决策阶段：没意识到问题
- 关键人物关系：老板/客户要求内容有效
- 用户判断题：为什么有播放但没有咨询
- 用户为什么会看：痛点具体，容易对号入座
- 用户看完拿走什么：知道查用户、信任、承接三件事
- 可信证据：真实账号复盘、截图打码、前后对比
- 为什么先拍：能筛出有真实转化需求的人

### 2. 客户说贵，不一定是嫌贵，可能是你没讲清这个判断标准

- 用户决策阶段：正在比较
- 关键人物关系：销售/顾问和客户
- 用户判断题：客户为什么不相信这个价格值
- 用户为什么会看：销售场景高频
- 用户看完拿走什么：知道先讲适配、风险、证据，不是先降价
- 可信证据：成交对话复盘、案例拆解
- 为什么先拍：直接连接商业结果

### 3. 老板 IP 最怕的不是不会说话，是第一条就把自己讲成广告

- 用户决策阶段：不信任
- 关键人物关系：老板面对客户、员工、同行评价
- 用户判断题：老板出镜怎么不尴尬、不自夸
- 用户为什么会看：老板出镜痛点强
- 用户看完拿走什么：知道先讲客户问题，再讲自己经验
- 可信证据：脚本前后对比、改稿案例
- 为什么先拍：适合老板 IP 课程/咨询承接

### 4. 什么人不适合报我的课？这 3 类人我会劝退

- 用户决策阶段：不信任
- 关键人物关系：用户和老师/顾问
- 用户判断题：这个老师是不是只想收钱
- 用户为什么会看：反销售，有信任感
- 用户看完拿走什么：知道适用边界
- 可信证据：真实筛选标准、服务边界
- 为什么先拍：高客单知识服务需要先建边界

### 5. 第一次咨询我，不用发一堆资料，先发这 4 个信息

- 用户决策阶段：准备行动
- 关键人物关系：用户和顾问
- 用户判断题：我下一步怎么开始
- 用户为什么会看：降低私信门槛
- 用户看完拿走什么：知道发行业、目标、现状、卡点
- 可信证据：咨询流程、表单打码
- 为什么先拍：把围观用户转成可判断线索

## 5. 素材清单

- 学员作业前后对比。
- 课堂片段。
- 私信高频问题打码。
- 账号复盘截图。
- 成交或咨询流程。
- 方法框架手写板。
- 不适合人群边界说明。

## 6. 给客户看的结论

知识 IP 的内容不要先证明老师多厉害，而是先证明这个方法能不能解决用户当前的具体场景。用户先觉得“这就是我卡住的地方”，才会愿意继续相信课程、咨询或陪跑。
